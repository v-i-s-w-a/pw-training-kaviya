# Playwright Training, Kaviya

Your repo for the Playwright and TypeScript training program.

Every homework from Session 4 on arrives here as a **pull request**. Your current task is in the **Issues** tab.

## The loop, every session
1. `git pull` to get the latest.
2. `git checkout -b <branch-name>` for a new branch.
3. Work, then `git add` and `git commit`.
4. `git push -u origin <branch-name>`.
5. Open a pull request, put `Closes #<issue-number>` in the description.
